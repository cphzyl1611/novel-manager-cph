
## 13. 回归风险记录

| 风险 | 说明 | 检查方法 |
|------|------|----------|
| app.js 缓存 | 浏览器可能加载旧版 JS | 看 Console 版本号、清缓存 |
| Service Worker 旧缓存 | SW 可能返回旧资源 | 更新 CACHE_NAME、Unregister |
| inline onclick | 某些按钮仍用 onclick | grep 检查 |
| progress 422 | 短小说分母为 0 | 打开不足一屏的小说 |
| stale incoming item | 已移动的书仍显示 | 检查更新分析页面 |
| 无效文件出现 | 已删除的书出现在首页 | 检查首页列表 |
